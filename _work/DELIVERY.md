## How it was rendered

Deterministic frame capture, not a screen recording:

1. `_work/adsite/ad.html` — a single self-contained composition. Every element is a pure
   function of time `T`, exposed as `window.__seek(T)`; the proof segment is drawn into a
   canvas from a seeked `<video>`, so frames are exact and repeatable.
2. `_work/serve.mjs` — tiny static server on `127.0.0.1:8123`.
3. `_work/render.mjs` — drives headless Google Chrome over the DevTools Protocol
   (zero npm dependencies), screenshots each frame at 1080×1920 and pipes the PNGs
   straight into ffmpeg.
4. `_work/encode.sh` — final mux, loudness-safe H.264 + AAC, faststart.

Re-render from scratch:

```bash
cd _work
node serve.mjs adsite 8123 &
node render.mjs --url http://127.0.0.1:8123/ad.html --pipe video/frames_raw.mp4 --fps 30 --crf 11
./encode.sh
```
